# System: Hermes — инструкция

System Hermes — локальное Flutter-приложение для самостоятельной жизни.
Основная навигация: **Главная**, **Работа**, **Деньги**, **Ещё**. Единственный
ИИ-агент приложения — **Hermes**.

## Установка на телефон

1. Открой репозиторий `Voronkov200/system_hermes` на GitHub.
2. Перейди в **Actions** → последний успешный запуск `Flutter Build APK`.
3. Скачай артефакт `release-apk`, распакуй ZIP и открой APK на телефоне.
4. Разреши установку приложений из браузера или файлового менеджера.
5. При обновлении устанавливай APK поверх прежней версии — локальные данные
   сохранятся.

## Подключение Hermes

Открой **Ещё → Настройки → Hermes Agent**.

Доступны режимы:

- **Свой сервер Hermes** — укажи URL и, если требуется, ключ сервера.
- **B.ai** — нажми «Создать API-ключ B.ai», создай ключ и вставь его без слова
  `Bearer`. Base URL `https://api.b.ai/v1` и модель `deepseek-v4-flash` уже
  выбраны по умолчанию.
- **Другая OpenAI-совместимая модель** — вручную измени Base URL и ID модели.

Если ни сервер, ни ключ модели не заданы, Hermes остаётся доступен в локальном
режиме и выполняет встроенные команды. Секреты хранятся только в настройках
приложения на телефоне.

Для голосовых сообщений нужен отдельный Groq API-ключ в поле «Groq API-ключ
для Whisper». Если голос не нужен, оставь его пустым: ключ B.ai используется
только для Hermes и не передаётся сервису транскрибации.

## Модули

- **Главная** — краткая сводка денег, тренировок и следующих действий.
- **Работа** — Учёба, План, Hermes Agent, Поиск, Документы и Obsidian.
- **Деньги** — официальный доход 390 BYN в месяц, общий BYN-счёт, локальные
  виртуальные карты BYN/USD/EUR/RUB, внутренние переводы и расчётная
  конвертация по курсам НБРБ.
- **Ещё** — Протокол тренировок, Журнал и Настройки.

Раздел «Деньги» является локальным планировщиком. Он не подключён к БСБ Банку,
не создаёт реальные карты и не выполняет настоящие банковские операции.

## Учёба и фото решений

- Гуманитарные предметы и языки используют локально извлечённый текст.
- Для точных предметов автоматические OCR-карточки отключены, потому что
  распознавание повреждает степени, корни, дроби и другие формулы.
- Кнопка **Фото решений по заданиям** открывает структуру ГДЗ: раздел → номер →
  оригинальное изображение решения.
- Каталог и каждое открытое фото сохраняются на телефоне. Для первой загрузки
  конкретного решения нужен интернет; затем оно открывается из кэша.
- Распознанный текст точного предмета остаётся только в свёрнутом блоке с
  предупреждением и не считается достоверной записью формул.

## Протокол тренировок

Протокол содержит только два ежедневных действия:

- отжимания ×20;
- приседания ×20.

Отдельно считается стрик каждого упражнения и общий стрик дней, когда выполнены
оба упражнения. Штрафных привычек и финансовых наказаний в протоколе нет.

## Локальные данные

Hive-боксы текущей версии: `accounts`, `transactions`, `habits`, `chat`,
`tasks`, `journal`, `docs`, `study`, `study_paragraphs`.

При обновлении приложение автоматически:

- переносит остатки со старых идентификаторов счетов в общий счёт и виртуальную
  карту;
- исправляет старые названия в истории операций;
- переводит нетронутую конфигурацию Groq без ключа на B.ai, но сохраняет
  собственный настроенный LLM-провайдер;
- удаляет устаревший пункт из протокола, не затрагивая тренировки.

## Разработка

- Проверки: `flutter analyze` и `flutter test`.
- Облачная сборка: GitHub Actions, workflow `Flutter Build APK`.
- Новая Hive-модель требует уникального `typeId` в `models.dart` и адаптера в
  `adapters.dart`.
