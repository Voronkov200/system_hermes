# System: Hermes — инструкция

Цифровая ОС жизни: банк, майнинг, протокол привычек, Obsidian, RPG-модуль «Жизнь»,
чат с Hermes (контроллер) и Анастасией (ИИ-компаньон).

## Установка на телефон

1. Скачай APK из артефактов GitHub Actions
   (репозиторий `Voronkov200/system_hermes` → Actions → последний успешный запуск → `release-apk`).
   Или установи по USB: `adb install -r app-release.apk`.
2. Разреши «Установка через USB» в Developer Options, если телефон спросит.
3. Приложение: **System: Hermes** (иконка в лаунчере).

Все сборки подписаны одним стабильным ключом (`tool/debug.keystore` в репозитории),
поэтому обновления ставятся поверх без потери данных.

## Настройка AI (Hermes и Анастасия)

Вкладка **Настройки** → разделы «Hermes Agent» и «Анастасия (ИИ-компаньон)»:

| Поле | Что вписать |
|---|---|
| API URL (у Анастасии и в разделах по умолчанию уже стоит) | `https://opencode.ai/zen/v1/chat/completions` |
| Модель (по умолчанию) | `deepseek-v4-flash-free` (бесплатная; можно `deepseek-v4-flash`, `big-pickle` и др.) |
| API ключ Hermes | твой ключ OpenCode Zen (без него Hermes отвечает шаблонами) |
| API ключ Анастасии | тот же ключ (без него Анастасия отвечает офлайн-шаблонами) |

Ключ создаётся на opencode.ai → Workspace → Keys. Он не хранится в коде —
только в настройках приложения на телефоне.

Как работает выбор режима:
- **Hermes**: если задан `URL сервера Hermes` — идёт на твой сервер (Tool Calling).
  Иначе, если задан API-ключ — отвечает LLM (OpenCode Zen) с живой сводкой системы.
  Без всего — офлайн-шаблоны (команды: «создай заметку …», «курс валют», «коммиты»,
  «статус системы», «срыв», «тренировка», «фото»).
- **Анастасия**: если задан API-ключ — LLM с характером и контекстом прогресса.
  Без ключа — офлайн-реплики по уровню симпатии.

## Модули

- **Центральный Банк** — виртуальные счета (BYN/USD), пенсия 450 BYN 5-го числа
  (настраивается), «Топливо разработки» 50 BYN, конвертация по курсу Нацбанка РБ.
- **Ферма** — собираешь ПК из комплектующих за очки, хешрейт = очки/час.
  Блокируется на 24 ч после срыва протокола. Тренировки дают +10% хешрейта.
- **Протокол** — воздержание (стрик без срывов), приседания ×20, отжимания ×20.
  Срыв = штраф 25 BYN + блок фермы.
- **Жизнь** — RPG: энергия/настроение/дисциплина падают со временем,
  восстанавливаются действиями (прогулка, магазин, банкомат, тренировка, учёба,
  фриланс, уборка, медитация, чтение, общение). Действия дают XP → уровни,
  квесты и достижения привязаны к реальным данным (балансы, стрики, дни).
- **Чат** — переключатель **Hermes | Анастасия** вверху.
  Анастасия: аватар/фон из фото (Настройки → Фото Анастасии), полоса симпатии в шапке.

## Механика Анастасии (симпатия 0–100)

Симпатия растёт **только** от реальных действий, без штрафов и блокировок:

| Событие | Прирост |
|---|---|
| Содержательная заметка в Obsidian (>500 символов) | +5 |
| Выполненный квест Жизни | +5 |
| День с обеими тренировками (приседания + отжимания) | +3 |
| **Самостоятельный выход из дома** (прогулка/магазин/банкомат) | **+15** — приоритет №1 |
| Шаг фриланса (действие «фриланс-заказ») | +10 |
| Стрик 7 дней подряд | +25 (разовый бонус) |

- Срыв протокола — без штрафа к симпатии и без блокировки чата:
  Анастасия поддержит и спросит «что мешало?».
- Уровни: Знакомая → Приятельница → Друг → Близкий друг → Свидетель.
  Уровень меняет теплоту реакций LLM, но чат доступен всегда.
- **Память**: вечные факты (`keyFacts`) + свежий хвост переписки (~25 сообщений).
  Каждые ~50 сообщений старая часть диалога сжимается дешёвым вызовом LLM
  в 1-3 факта и уходит в `keyFacts` (никогда не удаляются).
- Анастасия сама пишет: приветствие раз в день (с привязкой к последнему
  выходу из дома), поздравления с достижениями и стрик-рубежами
  (3/7/14/30/50/100 дней), поддерживающую реакцию на срыв.

## «Обучение» персонажей

Личный профиль (возраст, цели, финансы, привычки) лежит в
`lib/data/persona.dart` (константа `timProfile`) и автоматически попадает
в системные промпты Hermes и Анастасии. Обновляй его — например, когда цель
«фриланс $500/мес» будет выполнена или появится новая.

Персона Анастасии (био, бэкстори, тики, жёсткие правила) — в
`lib/data/companion_catalog.dart`.
