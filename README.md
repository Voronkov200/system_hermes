# System Hermes

**System Hermes** — персональная цифровая ОС для Android на Flutter. Приложение объединяет личный центр управления, работу и планирование, учебную систему 11 класса, Hermes AI, локальные финансы, привычки, журнал и Markdown/Obsidian-заметки.

> Репозиторий проекта: `https://github.com/Voronkov200/system_hermes`

## Навигация

Главная нижняя навигация состоит из четырёх разделов:

- **Главная** — состояние системы и быстрый доступ к важному;
- **Работа** — План, Учёба, Hermes, документы и заметки;
- **Деньги** — локальные счета, переводы и история операций;
- **Ещё** — привычки, журнал, Obsidian и настройки.

## Ключевые модули

| Модуль | Что делает |
|---|---|
| **Учёба** | 15 предметов 11 класса, 17 основных официальных PDF, параграфы, страницы учебников, предметные конспекты, ГДЗ, личные заметки, ошибки и интервальное повторение |
| **Hermes AI** | B.ai / OpenAI-compatible API или собственный Hermes Server; проверка API и понятные состояния ошибок |
| **Работа / План** | Задачи, записи, документы, поиск и рабочие инструменты |
| **Деньги** | Локальный финансовый центр: общий BYN-счёт, виртуальные счета BYN/USD/EUR/RUB, переводы, конвертация и история |
| **Obsidian / Markdown** | Работа с Vault-папкой, чтение и редактирование `.md`, файловый watcher |
| **Привычки и журнал** | Локальное отслеживание привычек и приватные записи |
| **Настройки** | Внешний вид, Hermes AI, Учёба, Vault, локальные данные и системные параметры |

> Раздел «Деньги» является локальным финансовым планировщиком. Он не подключается к банку, не создаёт настоящие банковские карты и не переводит реальные деньги.

# Учёба

Модуль «Учёба» строится вокруг одного учебного сценария:

```text
Учёба
  ↓
Предмет
  ↓
Глава / параграф
  ↓
┌────────────┬────────────┬─────────┬──────────────┐
│ Конспект   │ Учебник    │ ГДЗ     │ Повторение   │
└────────────┴────────────┴─────────┴──────────────┘
```

## Предметы

В каталоге представлены 15 предметных направлений:

1. Беларуская мова
2. Русский язык
3. Английский язык
4. Беларуская літаратура
5. Русская литература
6. История Беларуси в контексте всемирной истории
7. Обществоведение
8. География
9. Алгебра
10. Геометрия
11. Физика
12. Химия
13. Биология
14. Информатика
15. Астрономия

Английский язык и история используют по две части учебника, поэтому основных PDF — **17**.

Хрестоматии и сборники не входят в основную автоматическую очередь загрузки.

## Источники учебников

Основной источник — официальные электронные учебники Республики Беларусь:

- `https://e-padruchnik.adu.by/`
- `https://adu.by/`

Для каждого учебника Hermes хранит собственный `bookId` и смещение печатной страницы относительно PDF (`pageOffset`). Это позволяет связать конкретный параграф с правильной страницей официального PDF.

## Как отображаются страницы

Официальный PDF остаётся источником истины, но в мобильном интерфейсе требуемая страница подготавливается отдельно:

```text
официальный PDF
      ↓
нужная PDF-страница
      ↓
рендер в PNG высокого разрешения
      ↓
локальный кэш
      ↓
Image + zoom / pan
```

Это даёт стабильное отображение и офлайн-доступ после первого открытия.

Для точных формул OCR не считается источником истины: если текстовый слой повреждён, пользователь должен ориентироваться на оригинальную страницу учебника.

## Конспекты

Конспект не является универсальным AI-summary. Используются предметные структуры, например:

- **История:** причина → событие → результат → последствия;
- **Алгебра:** понятие → формула → ОДЗ → алгоритм → проверка;
- **Геометрия:** чертёж → дано → теорема → доказательство → ответ;
- **Физика:** явление → закон → величины → формула → применение;
- **Химия:** вещество → свойство → реакция → продукт → применение;
- **Биология:** условия → процесс → результат → значение;
- **Информатика:** задача → данные → алгоритм → программа → тест → исправление;
- **Астрономия:** наблюдение → объяснение → закон → практическое значение.

Факты извлекаются из учебного материала детерминированно. Если надёжного фрагмента нет, приложение не должно придумывать учебный факт.

Личные поля хранятся отдельно от учебного контента:

- «Мой пример»;
- «Мини-вывод»;
- «Что я не понял»;
- «Дополнение учителя»;
- «Мои ошибки».

## ГДЗ

Источник решений:

- `https://resheba.top/gdz/11-klass`

Hermes использует оригинальные изображения решений и локально кэширует уже открытые материалы.

Для длинных решений используется специальный viewer: изображение открывается примерно по ширине экрана, прокручивается вертикально и поддерживает pinch-to-zoom/pan. Оно не должно уменьшаться целиком по высоте экрана до нечитаемого размера.

## Повторение

В каждом параграфе есть интервальное повторение:

```text
10–15 минут → 1 день → 3–4 дня → 7 дней → 30 дней
```

Также есть вопросы для active recall и локальный список собственных ошибок.

Подробное техническое описание модуля и источников: [`docs/STUDY.md`](docs/STUDY.md).

# Hermes AI

Поддерживаются два режима:

1. **B.ai / OpenAI-compatible API**;
2. **собственный Hermes Server**.

Значения B.ai по умолчанию:

- Base URL: `https://api.b.ai/v1`
- модель: `deepseek-v4-flash`

В настройках есть кнопка **«Проверить API»**. Приложение различает ошибки авторизации, модели, лимита, сети и сервера. Случайно вставленный префикс `Bearer ` у ключа удаляется автоматически.

Ключ хранится локально и не добавляется в репозиторий.

# Сборка Android APK

CI находится в GitHub Actions и выполняет:

```text
Checkout
→ Flutter setup
→ dependencies
→ Android generation / patch
→ flutter analyze
→ flutter test
→ release APK
→ upload artifact
```

Локально:

```bash
flutter create --platforms android --org com.hermes --project-name system_hermes .
flutter pub get
bash tool/patch_android.sh
flutter run
```

Папка `android/` генерируется при сборке, а Android-конфигурация применяется через `tool/patch_android.sh`.

# Принципы проекта

- пользовательские данные хранятся локально там, где это возможно;
- личные заметки не должны исчезать при обновлении учебного контента;
- официальные учебники остаются первичным источником учебных фактов;
- точные формулы не восстанавливаются из повреждённого OCR;
- открытые учебные страницы и ГДЗ кэшируются для повторного использования;
- интерфейс должен оставаться полезным при нестабильном интернете;
- основная задача «Учёбы» — не хранить PDF, а помогать **изучить → проверить → повторить → запомнить**.
